# RPG Excellence V1

Production-ready starter for the RPG Excellence public website.

## Included
- Next.js App Router
- Responsive premium homepage
- EN / FR / PL / ES / IT language switching
- ISO 9001, 14001, 45001, 22301 and 27001 pages
- RPG Intelligence landing page
- About, Contact and Pricing
- Terms, Privacy and Cookie draft pages
- Mobile responsive design
- Ready for Vercel

## Local setup
1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`

## Deploy to Vercel
1. Upload this project to GitHub preserving folder structure.
2. Import the GitHub repository into Vercel.
3. Framework should auto-detect as Next.js.
4. Deploy.
5. Add `rpgexcellence.com` in Vercel Domains.
6. Update Cloudflare DNS using the records Vercel provides.
